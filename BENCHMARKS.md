# Formatting benchmarks

Every package against the native tool it is a compile of, measured on 2026-08-26.

Generated by `bun run bench` - see [`scripts/benchmark/README.md`](scripts/benchmark/README.md)
for what each row needs and how the numbers are taken. Two of them carry most of the
meaning:

- **Cold start** is one file in one process, nothing warmed up - a pre-commit hook, a
  one-shot CLI. Both sides pay their own startup, and the wasm side pays Node's too.
- **Steady state** is one more file through a process that is already up. The native
  side is the *marginal* cost of one more file inside a single invocation, so neither
  side is paying for startup in that row.

## Notes

- **ruby**: The default pipeline: syntax_tree, then `rubocop --autocorrect --only Layout`. Both sides run both passes in one process.
- **ruby-syntax-tree**: The same package with `{ rubocop: false }`, which is what isolates syntax_tree from the Layout pass.
- **php**: The native side runs the very phar the package ships, on a native PHP - so this is one tool on two runtimes.
