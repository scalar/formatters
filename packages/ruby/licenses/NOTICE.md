# Third-party notices

`@scalar/ruby-fmt` ships two compiled artifacts, `ruby_fmt.wasm` (CRuby with
syntax_tree) and `rbcop_fmt.wasm` (the RuboCop pass). This file carries the
notices the licenses of what is compiled into them require: each component's
copyright notice, and the text of the license it is distributed under. Each
distinct license text appears once, followed by every component it covers.
`cruby-LEGAL`, beside this file, is CRuby's own notice for the third-party code
compiled into CRuby itself.

Where a component offers a choice of licenses, it is distributed here under the
one named first in its entry, and the offer is shown. Crates that only run at
build time are not in either artifact and are not listed.

Generated by `build/licenses/collect.py`; do not edit by hand.
